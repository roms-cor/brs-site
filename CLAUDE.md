## Nomenclature (skill nommage-conversations)
- Scope de ce dépôt : brs/connect
- Branche : type/sujet-en-kebab, par exemple feat/page-coming-soon
- Commit : type(brs/connect): sujet à l'infinitif, minuscules, 72 caractères max, sans point final
- Session : dès que l'objectif est clair, /rename type(brs/connect): sujet
- Types : feat, fix, docs, data, plan, research, chore, refactor
- Si l'objectif change, le dire et proposer une nouvelle session plutôt que renommer
